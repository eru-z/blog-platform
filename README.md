# Blog Platform (Node.js)

A blog platform built using Node.js, Express, and EJS.

## Features
- User authentication (login & register)
- Create, edit, and delete blog posts
- Server-side rendering with EJS
- Protected routes

## Tech Stack
- Node.js
- Express
- JavaScript
- EJS
- HTML / CSS

## Setup
1. Install dependencies:
   npm install
2. Create a `.env` file
3. Run the server:
   node server.js

## Purpose
This project was built to practice backend development using Node.js and MVC-style architecture.
